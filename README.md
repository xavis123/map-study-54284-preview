# Map reading study, project 54284 (preview)

This is an online preview of the page used in the user study "Unravelling the Australian Map for
Improved Data Analysis" (Monash University, MUHREC project 54284). It is here so the supervisors
can try the questions and the two interactive ways before the study starts.

The study itself runs offline on the lab computer and is not run from this page. Nothing typed or
clicked here is sent anywhere. Add `?researcher=1` to the address for the screen menu.
